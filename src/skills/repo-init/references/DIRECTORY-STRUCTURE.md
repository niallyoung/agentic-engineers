# repo-init: Directory Structure Specification

**Purpose:** Defines the exact directory layout created in target repositories.  
**Version:** 1.0

---

## Overview

repo-init creates the following structure in the target repository.
Every directory and file listed is created by a specific phase of the skill.
Files marked `[TEMPLATE]` are rendered from `assets/`.

```
{repo_root}/
│
├── .agentic-engineers/              [Phase 5 + end-of-init]
│   ├── config.yaml                  [Phase 5] Framework configuration
│   ├── model-assignments.yaml       [Phase 5] Per-role model config
│   ├── models.yaml                  [Phase 5] Copied from framework
│   └── INIT-COMPLETE.yaml           [End]     Init success marker
│
├── agents/                          [Phase 3]
│   ├── README.md                    [Phase 3] Agent catalog (TEMPLATE)
│   ├── engineer.md                  [Phase 5] Engineer role (copied from framework)
│   ├── senior-engineer.md           [Phase 5] Senior role (copied)
│   ├── lead-engineer.md             [Phase 5] Lead role (copied)
│   ├── quality-engineer.md          [Phase 5] Quality role (copied)
│   ├── security-engineer.md         [Phase 5] Security role (copied)
│   ├── principal-engineer.md        [Phase 5] Principal role (copied)
│   └── orchestrator.md              [Phase 5] Orchestrator role (copied)
│
├── skills/                          [Phase 3]
│   ├── README.md                    [Phase 3] Skills index (TEMPLATE)
│   └── usage-tracking/              [Phase 5] Copied from framework
│       ├── SKILL.md
│       └── scripts/
│           └── usage-tracking.sh
│
├── tests/                           [Phase 3]
│   ├── README.md                    [Phase 3] Testing guide (TEMPLATE)
│   ├── conftest.py                  [Phase 3] Pytest configuration (TEMPLATE)
│   └── test_framework_init.py       [Phase 3] Smoke tests (TEMPLATE)
│
├── docs/                            [Phase 3 + Phase 2 + Phase 8]
│   ├── SPEC.md                      [Phase 2] Generated project specification
│   ├── AGENTS.md                    [Phase 8] Repo-specific agent config
│   ├── ONBOARDING.md                [Phase 8] New contributor guide
│   ├── QUICK-START.md               [Phase 8] Quick reference
│   └── index.md                     [Phase 3] Documentation index (TEMPLATE)
│
├── artifacts/                       [Phase 3] — gitignored
│   └── queue/
│       ├── incoming/                Incoming delegation tasks
│       └── done/                    Completed delegation tasks
│
├── TODO.md                          [Phase 7] Bootstrapped task list
├── README.md                        [Phase 4] Created or patched
├── .gitignore                       [Phase 4] Created or patched
└── Makefile                         [Phase 4] Created or patched (if needed)
```

### `tests/conftest.py`

```python
# conftest.py — pytest configuration for {project_name}
# Generated by repo-init v1.0
import pytest
from pathlib import Path

# Repository root (two levels up from tests/)
REPO_ROOT = Path(__file__).parent.parent


@pytest.fixture
def repo_root():
    """Absolute path to repository root."""
    return REPO_ROOT


@pytest.fixture
def tmp_repo(tmp_path):
    """Temporary directory initialized as a git repo (for integration tests)."""
    import subprocess
    subprocess.run(["git", "init", str(tmp_path)], check=True, capture_output=True)
    subprocess.run(
        ["git", "commit", "--allow-empty", "-m", "init"],
        cwd=str(tmp_path),
        check=True,
        capture_output=True,
        env={**__import__("os").environ, "GIT_AUTHOR_NAME": "test", "GIT_AUTHOR_EMAIL": "test@test.com", "GIT_COMMITTER_NAME": "test", "GIT_COMMITTER_EMAIL": "test@test.com"},
    )
    return tmp_path
```

### `tests/test_framework_init.py`

```python
# test_framework_init.py — Smoke tests for repo-init framework setup
# Generated by repo-init v1.0
# Pattern: test_<action>_<scenario>_<expected>
from pathlib import Path
import pytest

REPO_ROOT = Path(__file__).parent.parent


def test_directory_exists_agents_present():
    """agents/ directory should exist after framework init."""
    assert (REPO_ROOT / "agents").is_dir()


def test_directory_exists_skills_present():
    """skills/ directory should exist after framework init."""
    assert (REPO_ROOT / "skills").is_dir()


def test_directory_exists_docs_present():
    """docs/ directory should exist after framework init."""
    assert (REPO_ROOT / "docs").is_dir()


def test_file_exists_spec_md_present():
    """docs/SPEC.md should exist after framework init."""
    assert (REPO_ROOT / "docs" / "SPEC.md").is_file()


def test_file_exists_agents_md_present():
    """docs/AGENTS.md should exist after framework init."""
    assert (REPO_ROOT / "docs" / "AGENTS.md").is_file()


def test_file_exists_todo_md_present():
    """TODO.md should exist after framework init."""
    assert (REPO_ROOT / "TODO.md").is_file()


def test_file_exists_init_marker_present():
    """.agentic-engineers/INIT-COMPLETE.yaml should exist after successful init."""
    assert (REPO_ROOT / ".agentic-engineers" / "INIT-COMPLETE.yaml").is_file()


def test_todo_md_contains_required_sections():
    """TODO.md must contain Priority and Standard sections."""
    content = (REPO_ROOT / "TODO.md").read_text()
    assert "🔴 Priority" in content
    assert "🟡 Standard" in content


def test_spec_md_contains_agent_team_section():
    """docs/SPEC.md must contain Agent Team configuration."""
    content = (REPO_ROOT / "docs" / "SPEC.md").read_text()
    assert "Agent Team" in content or "agent-team" in content.lower()


def test_gitignore_contains_framework_entries():
    """'.gitignore must contain agentic-engineers entries."""
    gitignore = REPO_ROOT / ".gitignore"
    if gitignore.exists():
        content = gitignore.read_text()
        assert "artifacts/queue/" in content or "agentic-engineers" in content
```

## Makefile Additions

If a `Makefile` exists, Phase 4 appends these targets.
If no `Makefile` exists, a minimal one is created.

```makefile
# agentic-engineers targets (added by repo-init)
.PHONY: init-check validate-compat

init-check:  ## Verify agentic-engineers framework is correctly initialized
	@python3 skills/usage-tracking/scripts/usage-tracking.sh analyze 2>/dev/null || \
	  echo "usage-tracking not configured; run: make validate-compat"

validate-compat:  ## Run compatibility validation for agentic-engineers framework
	@python3 src/skills/repo-init/scripts/validate_compatibility.py \
	  --repo-root . --report
```
