# src/skills/

Each skill is a directory here with a `SKILL.md` (and, for script-backed skills,
`scripts/` and `tests/`). The skills registry, directory-structure rules and
per-role index live in a single place: [`src/SKILLS.md`](../SKILLS.md).

Validate with `python3 renderer/validate_skills.py` (or `make validate-skills`).
