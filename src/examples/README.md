# Examples

Reference implementations and usage patterns for the agentic-engineers framework.

## Files

- **budget_checker_examples.py** — How to use budget checking APIs
- **cost_attribution_example.py** — Track costs across agents and tasks
- **gradual_rollout_examples.py** — Implement gradual rollout strategies
- **orchestrator_cli_examples.py** — Use the orchestrator CLI programmatically
- **shadow_mode_integration.py** — Integrate shadow mode for testing
- **token_cost_monitoring.py** — Monitor and track token costs
- **token_tracker_examples.py** — Use the token tracker API

## Running Examples

Each file is standalone. Run with:

```bash
python3 src/examples/budget_checker_examples.py
python3 src/examples/cost_attribution_example.py
# ... etc
```
